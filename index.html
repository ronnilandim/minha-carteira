Usar no Celular (instalar como aplicativo)

Para usar esta carteira no seu celular como um app:
1. Hospede o arquivo online (gratis, 30 segundos)
Acesse app.netlify.com/drop no PC e arraste o arquivo carteira-investimentos.html. Vai gerar um link tipo https://nome-aleatorio.netlify.app. Anote esse link.
2. Instale no celular
iPhone (Safari): abra o link → toque no botao Compartilhar (quadrado com seta) → "Adicionar a Tela de Inicio".

Android (Chrome): abra o link → toque no menu (3 pontos) → "Instalar app" ou "Adicionar a tela inicial".
3. Pronto, abre como app
O icone aparece na tela inicial. Ao tocar, abre em tela cheia (sem barra do navegador), igual um app nativo. Funciona em qualquer celular.
Sincronizacao entre dispositivos: os dados ficam salvos por dispositivo (localStorage). Para levar a carteira do PC para o celular, use os botoes Exportar JSON (no PC) e Importar JSON (no celular). Envie o arquivo .json por WhatsApp/Drive/email.
